# Cadastre RO Domain Pack

**Domain:** Romanian Pre-Cadastre & Cadastral Registration  
**Legal Framework:** ANCPI Ordinul nr. 600/2023 (Anexa 1.34 / 1.35)  
**Standard Layer Conventions:** TopoLT (1CC, 2CC, CP, VARFURI, NUMERE_PCT, TABEL_PAD)  
**Maturity:** `MATURE`

## Capabilities
- `cadastral_dxf_export`: TopoLT-compliant DXF CAD export with layer hierarchy.
- `pad_coordinate_table`: Automated Stereo 70 (EPSG:3844) PAD table insertion in CAD model space.
- `cp_exchange_export`: ANCPI e-Terra ASCII `.CP` coordinate exchange file generation.
