# LiDAR Domain Pack

**Domain:** Airborne LiDAR & Elevation Processing  
**Data Formats:** ASPRS LAS / LAZ v1.2-1.4, GeoTIFF nDSM  
**Maturity:** `MATURE`

## Capabilities
- `ndsm_generation`: Normalized Digital Surface Model generation from classified point clouds.
- `building_height_extraction`: Extraction of statistical height profiles (mean, 95th percentile, standard deviation).
- `lidar_quality_gate`: Pre-processing validation of point density, vertical accuracy, and coverage completeness.
